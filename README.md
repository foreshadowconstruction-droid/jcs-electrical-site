# JCS Electrical landing site

Static HTML, CSS and JavaScript for the JCS Electrical ad landing pages. No build step.

- `index.html` is the home page. Each folder with an `index.html` is one landing page.
- `css/styles.css` and `js/main.js` are shared by every page.
- Quote forms post to a GoHighLevel inbound webhook. The address is set in `js/main.js` and in the four quiz landing pages.

Hosted on GitHub Pages from the `main` branch.
